# Wound Healing Size Tool

An ImageJ/Fiji macro (`.ijm`) for measuring wound size in wound healing assay images.

## Current version (2021)

- **Macro:** `Wound_healing_size_tool_updated.ijm`
- **Manual:** `Manual_Wound_healing_size_tool_updated.pdf` (usage instructions for the macro above)

These two files go together. Edit the `.ijm` file for code changes, and refer to the manual for how the tool is meant to be used.

## Older versions

Earlier releases are kept as zip files for reference only:

- `Wound_healing_size_tool .zip.zip` (April 2020)
- `Wound_healing_size_tool.zip` (June 2020, includes its own manual)
- `Wound_healing_size_tool_updated.zip` (June 2021, the zipped copy of the current macro and manual)

## Other files

- `RotateLogo.ijm` / `RotateLogo.zip`: small logo macro
- `.jpg` / `.tif` images: sample images
